## О проекте

**COSMO-NET** — высокопроизводительный интерактивный веб-сервис класса **Aerospace Mission Control Center** для проектирования и оценки устойчивости низкоорбитальной (LEO) спутниковой группировки связи в северных и приполярных районах.

### Ключевые параметры космического сегмента:
- **Группировка:** 48 спутников на круговой орбите высотой **550 км** с квазиполярным наклонением **87°**.
- **Архитектура орбит:** 3 орбитальные плоскости ($P_1, P_2, P_3$), по 16 аппаратов в каждой, сдвиги $\text{RAAN}$ ($0^\circ, 60^\circ, 120^\circ$), фазирование ($0^\circ, 7.5^\circ, 15.0^\circ$).
- **Очереди запуска:** 3 этапа по 16 аппаратов (интервал 3 месяца).
- **Наземная инфраструктура:**
  - Опорный шлюз: **Мурманск** (`G_MUR`, 68.97° с.ш., 33.07° в.д.).
  - Обслуживаемые терминалы: **C65** (65°N, 60°E), **C70** (70°N, 90°E), **C72** (72°N, 130°E).
- **Целевой показатель доступности связи:** $\ge 90\%$ расчетного времени для каждого терминала.
- **Горизонт расчета:** 86 400 секунд (24 часа), шаг 120 секунд (**720 отсчетов**).

## Архитектура решения и ключевые фичи

### 1. Двухрежимная визуализация
- **2D Арктическая азимутальная полярная проекция:** неискаженное отображение приполярных широт (вид на Северный полюс сверху), зон радиовидимости ($\ge 10^\circ$), сетки межспутниковых лазерных линий (ISL) и светящейся неоновой траектории активного маршрута.
- **3D Интерактивный орбитальный глобус:** объемная модель Земли на Three.js, кольца плоскостей под углом 87°, пространственные лучи связи и вращение камеры с зумом.

### 2. Временной док и интерактивная Gantt-диаграмма доступности
- Скраббинг от 0 до 86 400 секунд (24 часа) с мультипликаторами скорости (1x, 5x, 30x, 120x, 600x).
- **3-полосная лента доступности** для C65, C70, C72 с цветовой кодировкой:
  - 🟢 **Зеленый:** сквозной маршрут до шлюза активен.
  - 🟡 **Желтый:** спутник виден, но сеть разбита на изолированные сегменты (**ISL Mesh Partition**).
  - 🔴 **Красный:** нет спутника над абонентом или авария шлюза.
- Клик по любому месту ленты мгновенно перемещает симуляцию в данный момент времени.

### 3. Интеллектуальный диагностический модуль (Root Cause Analysis)
При отсутствии маршрута система четко определяет первопричину:
1. `NO_VISIBLE_SATELLITE`: отсутствие активных спутников с углом возвышения $\ge 10^\circ$.
2. `ISL_MESH_PARTITION`: над абонентом есть спутник, но в межспутниковом графе нет связного пути до спутников над Мурманском.
3. `GATEWAY_NO_SATELLITE`: отсутствие спутников в зоне радиовидимости шлюза.
4. `GATEWAY_OUTAGE`: регламентная недоступность наземного шлюза.

### 4. Центр моделирования отказов и «Экспресс-авария»
- Возможность задавать регламентные отказы любых аппаратов и шлюза.
- **Кнопка экспресс-теста:** отключение транзитного КА прямо из текущего маршрута в один клик для демонстрации жюри динамической перемаршрутизации сети в реальном времени!

### 5. Сравнение проектов и генератор рекомендаций
- Сопоставление двух конфигураций бок о бок с дельтой KPI ($\Delta$ Доступность %, $\Delta$ Макс. перерыв).
- Синхронное сравнение временных шкал.
- Готовый аналитический отчет для 5-минутного питча перед жюри.

### 6. Строгое соответствие спецификации
- Валидация входных данных по схеме `cosmo-A-1.0`.
- Экспорт результатов по официальному стандарту `cosmo-A-result-1.0` (2160 записей маршрутов).

## Инструкция по запуску

### Вариант 1: Быстрый запуск Frontend (Рекомендуемый)
```bash
cd frontend
npm install
npm run dev
```
Сервис откроется по адресу: **http://localhost:5173**

### Вариант 2: Запуск с локальным Python Backend
В первом терминале:
```bash
cd backend
python -m pip install -r requirements.txt
python app.py
```
Во втором терминале:
```bash
cd frontend
npm run dev
```

### Вариант 3: Запуск через Docker Compose (в 1 команду)
```bash
docker compose up --build
```
Веб-интерфейс будет доступен по адресу: **http://localhost:3000** (бэкенд: **http://localhost:8000**).

### Верификационный тест математического движка
```bash
python verify_all_scenarios.py
```
Проверяет валидацию, точность формул кинематики, маршрутизацию и экспорт на всех 4 сценариях.
